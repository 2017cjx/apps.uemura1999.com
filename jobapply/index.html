JobApply

JobApply is a personal tool run by one person (the developer) on their own server to help with their own internship applications. It is not offered to anyone else.

It uses read-only access to the developer's own Gmail account to:

  • read the verification codes job application sites email after an application is submitted, and
  • find employer emails that need a reply or another step (for example an online assessment or interview scheduling) and remind the developer about them.

It never sends, deletes or changes email.
