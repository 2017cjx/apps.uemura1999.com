JobApply privacy policy

Last updated: October 20, 2026

JobApply is used only by its developer, with the developer's own Google account. No one else's data is accessed.

What it accesses

Gmail, read-only (gmail.readonly): the developer's own messages, to find job-application verification codes and employer emails that need action. It never sends, deletes, labels or changes email.

What it stores

On the developer's own server only: for job-related emails, the sender, subject, a short summary and any deadline; for other emails, only the message id and date (so they are not read again). Email bodies are not stored. The access token is stored on the same server and is not shared.

What it sends elsewhere

  • The text of emails that look job-related is sent to the Anthropic API to classify them (for example "assessment" or "rejection"). Other emails are not sent.
  • Short reminders (sender, subject, summary, deadline) are posted to the developer's own private Slack channel.

Data is not sold, shared for advertising, or used for any other purpose. Use of data obtained through Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
